Cuatro Ecosystem — four design directions

Same content, four complete visual personalities. All dark-only, all anchored on a single purple hue, all built to hallmark's rules: no pure #000, no gradients, no glow, accent held under 3% of viewport. They differ on density, type voice, and how much the page performs — not on hue.

Each panel shows the homepage climax (the narrative's last beat resolving into the Suite Directory) and two real Registry Entries with a Live and a Complete state. Descriptions are drafts written to the FR-8 contract.

Swatch values are documented as OKLCH with hex approximations in the <style> comments — lift them straight if you pick one.

ATerminal Ledgeran ops console that happens to be beautiful

Mono-forward and dense. The Suite Directory is a table, not a card grid — which kills hallmark's three-column-card tell outright and reads as a status board rather than a portfolio. Purple appears only as a live-state indicator and a link underline. Strongest for Marcus; the risk is that Daniela reads it as documentation rather than as a person.
