- (change) CRITICAL FIX 1 - token namespace collision. The @theme inline adapter mapped Tailwind's --color-bg to var(--color-bg), the same name on both sides. That is a self-reference that survives only if tokens.css happens to be imported unlayered and out-cascades Tailwind's theme layer; under a bundler flatten or a layer wrap it becomes a cycle, invalid at computed-value time, and the property falls back to transparent. The semantic role layer is renamed --color-* to --token-* throughout, matching research D2's own --color-brand: var(--token-brand) convention. Distinct namespaces make the failure structurally impossible rather than accidentally avoided.
- (change) CRITICAL FIX 2 - cs-tracker was filed as a plain-CSS consumer, but Phoenix 1.8.0 ships Tailwind v4 plus daisyUI, and research D2 is explicit that a plain :root file generates ZERO utility classes in a Tailwind app. The Tailwind cluster is therefore cuatro-finance + cuatro-tracker + cs-tournament PLUS cs-tracker - which is the Step 2 adopter FR-18 is measured on.
